# Kindle and EPUB Edition

| File | Use |
|---|---|
| `Kindle_Create_Import_The_Little_Money_Makers.pdf` | **For Amazon Kindle.** Import into Kindle Create (fixed-layout comics/children's book option), check every page, export the `.kpf` and upload that to KDP. |
| `Kindle_Page_Images_2048px/` | The same 36 pages as 2048 × 2048 px JPEG images, if you prefer an image-folder import. |
| `The_Little_Money_Makers_Fixed_Layout.epub` | Fixed-layout EPUB 3 for Apple Books, Kobo and Google Play. Validated with EPUBCheck 3.4: 0 errors, 0 warnings. Each page image carries the full page text as alternative text. |

## Why not a normal reflowable EPUB?
A picture book depends on the illustration and text staying together on the page. A reflowable EPUB lets the reading app move text and images around, which breaks the layout. Amazon retired the Kindle Kids' Book Creator; illustrated books now go through Kindle Create, which produces KDP's KPF format from a PDF. A KPF file can only be made in that desktop app, so it is not included here.

Fixed-layout Kindle books display on Fire tablets and the Kindle apps. Older e-ink Kindles have limited support for them.
